# Royal Haven — Luxury Restaurant Website

A modern, elegant, luxury restaurant homepage made with JavaScript and JSX.

## How to run

```bash
npm install
npm run dev
```

Then open:

```bash
http://localhost:3000
```

## Add your images

Place your own images inside:

```bash
public/images/
```

Use these exact names:

- `hero.jpg` — main homepage hero image
- `exterior.jpg` — hotel/restaurant exterior
- `entrance.jpg` — entrance view
- `interior.jpg` — interior view

You can replace the text later inside:

```bash
src/app/page.jsx
```
